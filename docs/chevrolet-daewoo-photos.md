# 쉐보레 · 대우 차량 사진 파일명 체크리스트

## 사용 방법
1. 사진을 구한다.
2. 아래 **지정 파일명**으로 바꾼다. (확장자 `.png` 권장, 기존 사이트와 동일)
3. `public/images/cars/` 폴더에 넣는다.
4. 사이즈(mm)는 `data/chevrolet-daewoo.json`의 `driver_mm` / `passenger_mm`를 검증 후 채운다.
5. 사이즈가 채워진 뒤에 사이트 빌드에 연결한다.

> 맞습니다. **파일명만 아래와 똑같이** 맞추면 됩니다. 폴더 위치는 `public/images/cars/`.
