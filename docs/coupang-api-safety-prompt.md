# 쿠팡 파트너스 검색 API 안전화 프롬프트

다른 사이트/레포에 그대로 붙여 넣어 적용하세요.

```text
[목표]
쿠팡 파트너스 OpenAPI(상품 검색) 호출이 공식 한도를 넘지 않도록, 이 레포의 쿠팡 연동을 감사하고 안전한 호출/캐시 구조로 고친다.
지금은 “이용 제한”을 이미 경험한 상태이므로, 공격적 재시도·강제 새로고침·실시간 검색 호출은 금지한다.
코드 수정 전에 먼저 호출 지점을 모두 찾고, 변경은 최소·안전하게 한다.

[공식 한도 — 반드시 이 숫자를 하드 가드로 반영]
- 검색 API: 1시간당 10회
- 리포트 API: 1시간당 50회
- 모든 API: 1분당 100회
- 파트너스 웹 링크생성: 1분당 50회
- 위 한도 초과 경고가 누적 3회면 계정 이용 제한될 수 있음

[절대 금지]
- 사용자 요청(페이지뷰)마다 검색 API를 호출하는 구조
- 분당 50회(웹 링크생성) 또는 시간당 10회(검색 API)에 근접한 루프
- 실패(403 등) 후에도 재시도로 한도를 추가 소모하는 로직
- ads-partners.coupang.com/g.js 다이나믹 배너를 새로 넣거나 복구
- --refresh / force 옵션이 한도 가드를 우회하게 두기

[조사]
1. 쿠팡 관련 호출 전부 찾기: api-gateway.coupang.com, products/search, HMAC, COUPANG_ACCESS_KEY, link.coupang.com, ads-partners, g.js, partners.coupang.com
2. 런타임(브라우저/서버 SSR) vs 빌드타임 vs 크론/수동 스크립트 구분
3. 현재 캐시 여부, TTL, 강제 갱신 플래그, 동시 실행 가능성 확인
4. README/배포 문서에 한도·주의사항이 있는지 확인
5. 상품을 가르는 축(예: 와이퍼 운전석mm+조수석mm, 카테고리, 모델 옵션)이 데이터에 있는지 확인

[키워드/캐시 키 — 에이전트가 자동으로 할 일]
- 사용자가 사이즈·키워드 목록을 일일이 주지 않아도 된다.
- 레포 데이터(시트/JSON/CSV/DB 등)에서 상품 매칭에 쓰는 조합을 추출해 **고유 키 집합**을 자동 생성한다.
  예(와이퍼): driver_mm + passenger_mm → 캐시 키 `650-450`, 검색 키워드 `불스원 650 450`
  예(일반): 카테고리/옵션 코드 → 캐시 키와 검색 키워드를 도메인에 맞게 규칙으로 만든다.
- 이미 `coupang_keyword` 같은 필드가 있으면 그걸 우선하고, 없으면 위 규칙으로 기본 키워드를 만든다.
- 차량/상품이 수백 개여도 API는 “고유 조합 수”만큼만 호출한다. (같은 650-450은 1회만)
- 빌드/배치 시: 고유 키별로 검색 API(한도 내) → `data/products/{key}.json` 등 캐시 저장 → 각 결과 페이지 HTML에 상품 카드 + 정적 제휴 URL(`link.coupang.com` 또는 API가 준 productUrl)을 심는다.
- 방문자는 캐시된 HTML만 본다. 페이지뷰마다 검색 API 호출 금지.
- 고유 키가 시간당 한도(10회, 실사용 6~8회)보다 많으면 한 번에 다 돌리지 말고, 이번 배치에서 상한만 갱신하고 나머지는 다음 시간/다음 빌드로 미룬다.

[필수 조치]
A. 검색 API는 “사전 수집 + 캐시”만 허용 (방문/요청 경로 API 0회)
B. 시간당 검색 API 하드캡: 기본 최대 6~8회(10회 미만 여유)
C. 배치/빌드당 상한 + 남은 키워드는 다음 시간으로 미룸
D. 연속 호출 최소 1~2초 간격
E. 403/제한 응답 시 즉시 전체 중단 (같은 시간창 추가 호출 금지)
F. refresh 플래그도 하드캡·하드스톱 우회 불가
G. g.js/다이나믹 배너 제거, 정적 파트너스 링크만
H. README에 공식 한도·3회 제한·운영 규칙 명시
I. 위 [키워드/캐시 키] 규칙으로 고유 조합·키워드·캐시 파일을 자동 구성 (수동 목록 입력에 의존하지 말 것)

[완료 조건]
1) 런타임 검색 API 0
2) 시간당 하드캡+403 하드스톱
3) g.js 없음
4) README 반영
5) “이 레포 시간당 최대 N회”를 숫자로 보고
6) 고유 캐시 키 규칙(예: `{운전}-{조수}`)과 기본 검색 키워드 규칙을 보고하고, 샘플 2~3개 제시
쿠팡 호출 안전화만 하고 무관 리팩터/디자인 변경 금지.
```
